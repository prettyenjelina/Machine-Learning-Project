# Machine Learning Projects

## About This Repository

Welcome to my Machine Learning portfolio! This repository contains a collection of projects exploring different machine learning algorithms and techniques using Python.

The projects cover classification, clustering, and comparisons between machine learning models to understand their performance and practical applications.

## Projects

### 1. Decision Tree vs Naive Bayes
Exploring and comparing Decision Tree and Naive Bayes algorithms for classification tasks.

### 2. K-Means vs Artificial Neural Network (ANN)
Exploring K-Means clustering and Artificial Neural Networks to understand their approaches and applications.

### 3. Artificial Neural Network (ANN)
A project focused on applying the Artificial Neural Network algorithm to a machine learning problem.

### 4. Support Vector Machine (SVM)
A project exploring the Support Vector Machine algorithm for machine learning tasks.
